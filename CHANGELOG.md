# Changelog

All notable changes to `3neti/x-commerce` are documented here.

## 1.0.0 - 2026-07-31

- Establish the versioned Pay Code commercial catalog as the pricing source of truth.
- Add deterministic quote and immutable sale snapshot primitives.
- Add the pure, provider-independent Commercial Waterfall calculator.
- Price collectible, payable, settlement, onboarding, input, validation, feedback, and Rider instructions.
- Preserve the package boundary: x-commerce calculates allocations but does not post funds.
- Add commercial architecture, projection, evidence, and financial-model documentation.
