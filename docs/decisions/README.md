# Commercial Architecture Decision Records

Decision records preserve commercial architecture choices, assumptions, and deferred boundaries.

## Status Values

- Proposed: suggested direction under review.
- Accepted: current working position.
- Superseded: replaced by a later decision.
- Rejected: considered and declined.
