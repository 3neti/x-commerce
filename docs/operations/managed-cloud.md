# Managed Cloud Operations

## Potential Responsibilities

- cloud provisioning;
- CI/CD;
- secrets and environment management;
- deployment automation;
- uptime monitoring;
- backups;
- restoration exercises;
- logging;
- alerting;
- patching;
- certificate maintenance;
- incident response;
- release support;
- security hardening coordination;
- disaster-recovery procedures;
- cost monitoring;
- capacity planning.

## Commercial Models

1. Rural bank contracts directly with DevOps provider.
2. ODTI contracts with DevOps provider and resells managed operations.
3. ODTI bundles managed hosting into a platform subscription and pays the DevOps provider under a wholesale arrangement.
