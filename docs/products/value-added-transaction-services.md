# Value-Added Transaction Services

## Outcome

Additional services attach to a transaction to improve communication, eligibility, evidence, engagement, risk control, or reporting.

## Examples

- SMS;
- email;
- KYC;
- OTP;
- digital signature;
- selfie;
- face match;
- location verification;
- feedback;
- surveys;
- rider URL or CTA;
- document collection;
- fraud or risk analysis;
- reporting;
- archival evidence;
- reconciliation;
- premium support.

## Pricing Rule

Separate provider cost, markup, taxes, and revenue allocation for every service.
