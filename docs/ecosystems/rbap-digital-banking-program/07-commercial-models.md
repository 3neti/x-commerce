# Commercial Models

## Software And Licensing

### Model A: Perpetual License And Maintenance

- one-time license: working assumption around PHP 100,000;
- annual maintenance: working assumption around 18% of license price.

### Model B: Annual Subscription

- annual subscription: working assumption around PHP 60,000 to PHP 120,000.

### Model C: Hybrid

- onboarding or activation: working assumption around PHP 50,000;
- annual platform subscription: working assumption around PHP 60,000.

## Base Transaction Fee

Working assumption: around PHP 1 to PHP 2 per completed disbursement or qualifying transaction.

## Value-Added Services

Working assumptions:

- SMS notification: around PHP 1.00;
- email notification: around PHP 0.10;
- KYC: around PHP 25.00;
- rider URL or CTA: around PHP 50.00.

Each model must separate customer-facing price, provider cost, gross markup, gross margin, taxes, settlement or rail charges, bank-retained revenue, and net platform revenue.
