# Roadmap

## Phase 1: Documentation And Commercial Architecture

Current.

- Establish package identity.
- Define vocabulary.
- Document RBAP as the first ecosystem.
- Build stakeholder maps.
- Record working assumptions.
- Separate money-flow categories.
- Create financial model templates.
- Identify risks, legal dependencies, and unresolved decisions.

## Phase 2: Stakeholder Financial Models

Proposed.

- Draft complete RBAP program overview.
- Build Conservative, Base, and Accelerated scenarios.
- Create separate five-year views for each major stakeholder.
- Prepare presentation-ready source material.
- Validate provider costs and bank adoption assumptions.

## Phase 3: Approved Commercial Interfaces

Future.

- Introduce pricing, offering, metering, commission, royalty, revenue-share, subscription, entitlement, and invoice contracts only after commercial decisions are approved.
- Add tests for public interfaces and compatibility.

## Phase 4: x-change Extraction

Deferred.

- Inventory commercial logic in x-change.
- Characterize behavior.
- Create tests.
- Record extraction decision.
- Migrate incrementally without changing behavior.
