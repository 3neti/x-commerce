# Managed Cloud

## Working Pricing

- deployment setup: around PHP 50,000 per bank;
- monthly maintenance: around PHP 10,000 per bank;
- annual recurring total: around PHP 120,000 per bank, excluding setup.

## Delivery Structures

### Rural Bank Contracts Directly

Advantages: clear provider relationship and direct accountability.

Risks: ODTI has less control over operations and support coordination.

Margin implication: ODTI does not earn cloud margin unless separately contracted.

### ODTI Resells Managed Operations

Advantages: single commercial interface for the bank.

Risks: ODTI carries support and vendor accountability.

Margin implication: ODTI may earn markup if priced above provider cost.

### ODTI Bundles Managed Hosting

Advantages: simpler offer and predictable package.

Risks: poor cost control can erode subscription margin.

Margin implication: wholesale provider cost must be tracked against bundled price.
