# Transaction Fees

## Working Assumption

Base transaction fee may be around PHP 1 to PHP 2 per completed disbursement or qualifying transaction.

## Required Model Fields

- transaction type;
- chargeable event;
- customer-facing price;
- bank-retained amount;
- ODTI platform charge;
- 3neti royalty, if applicable;
- rail or settlement fee;
- taxes;
- refund or reversal treatment.
