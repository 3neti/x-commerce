# Licensing

## Working Models

Model A: perpetual license around PHP 100,000 plus annual maintenance around 18%.

Model B: annual subscription around PHP 60,000 to PHP 120,000.

Model C: hybrid activation around PHP 50,000 plus annual platform subscription around PHP 60,000.

## Required Distinctions

- 3neti IP ownership;
- ODTI commercial operation;
- rural-bank license through ODTI;
- sublicense rights, if any;
- implementation and hosting exclusions;
- maintenance obligations;
- royalty basis.
