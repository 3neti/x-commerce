# Economics

The economics section documents pricing, costs, markups, margins, commissions, referrals, royalties, revenue sharing, unit economics, break-even, five-year projections, and sensitivity analysis.

Every model must distinguish:

- customer-facing price;
- direct provider cost;
- gross markup;
- gross margin;
- revenue-share allocation;
- taxes;
- settlement or rail charges;
- bank-retained revenue;
- net platform revenue.

No model in this directory is a guaranteed forecast or approved contract.
