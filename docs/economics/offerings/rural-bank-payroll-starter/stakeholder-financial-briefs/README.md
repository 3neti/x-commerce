# Payroll Starter Stakeholder Financial Briefs

## Governance Rule

These briefs are different presentations of the same canonical Level 1 Payroll Starter model.

They do not contain independent calculations.

All numbers originate from:

- [offering-economics-level-1.md](../offering-economics-level-1.md)
- [five-year-revenue-projection-summary.md](../five-year-revenue-projection-summary.md)
- [provisional-input-register-level-1.md](../provisional-input-register-level-1.md)

If a number changes, the canonical Level 1 model changes first. The stakeholder brief merely reflects it.

## Required Warnings

> This brief uses provisional management candidates and controlled placeholders. It is not a forecast, approved budget, provider quote, institutional commitment, investment representation, contract, or factual operating result.

> Stakeholder revenue figures are entity-level views and include internal ecosystem transfers. They are not additive. Consolidated External Revenue counts external customer inflows once and eliminates internal transfers.
