# x-commerce Documentation

`x-commerce` is the commercial architecture and knowledge system for packaging, pricing, licensing, metering, and sustaining outcomes delivered through the x-change ecosystem.

This MkDocs site is a presentation layer over the Markdown already maintained in `docs/`. The canonical source remains the repository documentation itself.

## Start Here

- [Compass](COMPASS.md) gives the high-level purpose, boundaries, current state, and invariants.
- [Architecture](ARCHITECTURE.md) explains the knowledge architecture and future software boundaries.
- [Commercial Grammar](GRAMMAR.md) defines the vocabulary used across the package.
- [Assumptions Register](ASSUMPTIONS_REGISTER.md) records working assumptions that require evidence or approval.
- [Decision Register](DECISION_REGISTER.md) points to commercial architecture decision records.
- [MkDocs Support](MKDOCS.md) explains how this site discovers and orders documentation.

- [Five-Year Revenue Projection Summary](economics/offerings/rural-bank-payroll-starter/five-year-revenue-projection-summary.md): the current Payroll Starter projection summary.

- [Ecosystems](ecosystems/rbap-digital-banking-program/README.md): the first working ecosystem subject, the RBAP Digital Banking Program.
- [Operations](operations/README.md): deployment, managed cloud, onboarding, service levels, and support boundaries.
- [Legal Handoffs](legal/README.md): commercial-to-legal dependencies and x-legal handoff material.
- [Partners](partners/README.md): non-binding participation models and formalization backlog.
- [Templates](templates/assumption-record.md): reusable drafting formats for assumptions, decisions, pricing, models, money flow, and stakeholder cases.

## Reading Path

New readers should begin with the [Compass](COMPASS.md), then read the [Architecture](ARCHITECTURE.md) and [Commercial Grammar](GRAMMAR.md). From there, move to [Stakeholders](stakeholders/README.md), [Economics](economics/README.md), and the [Rural Bank Payroll Starter Offering Model](economics/offerings/rural-bank-payroll-starter/README.md).

The documentation is evolving. Where a page labels material as provisional, blocked, deferred, a working assumption, or requiring legal, accounting, tax, privacy, operational, or stakeholder validation, read it accordingly.
