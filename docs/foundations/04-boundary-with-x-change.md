# Boundary With x-change

## x-change

x-change answers:

```text
How is a value-bearing instruction represented, authorized, executed, completed, and evidenced?
```

It owns execution concepts such as instructions, vouchers, claims, execution drivers, execution modes, lifecycle, settlement, redemption or disbursement, execution state, and transactional evidence.

## x-commerce

x-commerce answers:

```text
How is an outcome packaged, priced, licensed, sold, metered, commissioned, and made commercially sustainable?
```

It may eventually own commercial offerings, prices, rate cards, licensing plans, maintenance, subscriptions, usage billing, transaction charges, value-added service pricing, marketplace economics, commissions, royalties, referrals, revenue sharing, catalogs, carts, checkout, orders, and invoices.

## Current Rule

No production commercial logic has yet been extracted from x-change.

Future extraction requires characterization tests and a separate decision record.
